The API project's license covers its software, not the individual sound recordings. Each marketplace result links to its MyInstants source page. The [MyInstants terms](https://www.myinstants.com/en/terms_of_use.html) include restrictions concerning automated requests and downloading site content. Users should review those terms and each sound’s rights before installing, using or sharing a recording.
